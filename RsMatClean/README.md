# RsMat Clean

版本：`1.2.4`  
插件 ID：`1069687`  
适用版本：Cinema 4D 2024–2026

## 简短说明

RsMat Clean 用于清理材质节点图中未被最终输出使用的节点，支持 C4D 节点材质、Redshift 和 Octane 经典材质节点。

插件从材质最终输出反向检查连接关系。能够到达输出的节点会被保留；孤立节点、孤立节点链和无法到达输出的节点会进入待删除列表。缺失贴图、禁用节点或参数为零不会单独触发删除。

## 安装

1. 解压发布 ZIP。
2. 将完整的 `RsMatClean` 文件夹复制到 Cinema 4D 的 `plugins` 目录。
3. 完全退出并重新启动 Cinema 4D。
4. 在命令管理器中搜索 `RsMat Clean`，可直接运行或拖入工具栏。

插件会根据 Cinema 4D 界面语言自动显示中文或英文。

## 使用方法

1. 建议先备份当前 `.c4d` 工程。
2. 在材质管理器中决定处理范围：
   - 单选：只处理该材质。
   - 多选：处理全部已选材质。
   - 无选择：处理当前工程全部材质。
3. 运行 `RsMat Clean`。
4. 在控制台检查待删除节点清单。
5. 在确认窗口点击“是”后才会执行删除。

## 撤销与注意事项

- 支持 Cinema 4D 撤销；处理多个材质图时可能需要多次 `Ctrl+Z`。
- Surface、Displacement、Volume 等已接入最终输出的分支都会保留。
- 无法安全读取或只读的节点图会被跳过，不会强制删除。
- 首次用于 Redshift 或 Octane 工程时，建议先在工程副本上核对预览结果。
